# 話題と会話の構成（チーム確認用・暫定公開）

本ディレクトリは、グループディスカッション分析の内部ダッシュボード v2.2 を、
チーム確認のために GitHub Pages へ暫定公開したものです。

## 重要：これはアクセス制限ではありません

`index.html` の `<head>` には次のメタタグを入れています。

```html
<meta name="robots" content="noindex,nofollow,noarchive">
```

**これは検索エンジンによるインデックス登録を避けるための補助的な指示であり、アクセス制限ではありません。**

- URL を知っている人は誰でも閲覧できます。
- メタタグに従うかどうかはクローラ側の任意であり、強制力はありません。
- 公開済みの内容は、第三者のキャッシュやアーカイブに残る場合があります。
  後からリポジトリや GitHub Pages を private に戻しても、それらは消えません。

限定配布が必要な場合は、この仕組みではなく、アクセス制御のある配布手段を使ってください。

## 公開しているファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面本体 |
| `dashboard.css` | スタイル |
| `dashboard.js` | 描画・操作ロジック |
| `dashboard_data.js` | 集計済み表示データ |

外部ライブラリ・外部通信は使用していません。すべて同一ディレクトリ内の静的ファイルで完結します。

## 表示内容の性質

- 画面上の数値は **AI による暫定判断（AI暫定値）を含みます**。確定値ではありません。
- 対象は 2 セッションのみの **小標本** です。一般化できません。
- セッション G／B の比較は、**今回の 2 セッションで観察された傾向** を示すものです。
  性別による一般的な差を示すものではありません。
- 人間コーダー間信頼性、個人の心理特性、因果関係を示すものではありません。
- 件数 5 未満のセルは `≤4` と表示し、実数を伏せています（小セル秘匿）。
- 要配慮の話題は、抽象ラベルと件数のみを表示し、詳細は表示していません。

## 公開していないもの

次は本ディレクトリに含まれておらず、リポジトリの `.gitignore` でも除外しています。

- 発話本文、直接引用、音声・映像、ASR 出力、話者分離結果（RTTM）
- 話者ID・参加者ID・氏名対応表、発話単位の時刻、クリップのパス
- 分析台帳、裁定台帳、レビュー用 CSV、QA 成果物、生成スクリプト

## 公開範囲の変更について

この公開は暫定です。確認が終わったら、リポジトリおよび GitHub Pages の公開範囲を
見直してください。上記のとおり、公開停止は「すでに取得された内容」までは取り消せません。
