# 輪郭場（作品ページ）

公開済みの会話テーマ（`../dashboard/`）と視覚資料（`../visual-materials/`）の構成を、
同じ場に置き、色・線・動きとして翻訳するインタラクティブ作品です。

URL: `docs/artwork/`（GitHub Pages）

## 二つの操作の役割

| 操作 | 決めるもの | 決めないもの |
|---|---|---|
| 会話テーマ | 作品の変わり方（色の比重・動きの速さ・ほつれ・粒子の振る舞い・余白の頻度） | 描かれる輪郭 |
| 視覚資料 | 描かれる輪郭・色・構図 | 作品の変わり方 |

二つは作用する対象が重ならないため、両方を選んでも別々の層として重なるだけです。
テーマと資料を対応づける処理はありません。

G と B は記録が行われた範囲の区別です。範囲どうしを比べる表示（件数・割合・優劣）は作りません。

## URL

| パラメータ | 例 |
|---|---|
| `session` | `?session=g` |
| `materials` | `?materials=group-g-01,group-g-03` |
| `theme` | `?theme=学校・進路`（要URLエンコード） |

組み合わせ: `?session=b&theme=将来・見通し`

未知の値、内部形式の識別子、一部でも不正な値を含む `materials` は、そのパラメータ全体を無視し、
静かな初期状態（1資料・テーマ未選択）で開きます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構成、常設注意書き |
| `artwork.css` | 表示 |
| `artwork.js` | 描画と操作 |
| `artwork_renderer.js` | 基準輪郭の描画 |
| `artwork_relation_map.js` | 公開テーマ → 造形パラメータの変換規則 |
| `artwork_contours.js` | 公開済み視覚資料に由来する縮約済みの輪郭と代表色 |

外部ライブラリ・外部通信・Cookie・保存は使いません。読み込むのは上記6ファイルだけです。

## 公開データについて

`artwork_contours.js` が持つのは、公開済み画像 `group-g-01` … `group-b-04` に由来する次のものだけです。

- 正規化座標の輪郭（小数3桁。画面比およそ 1/1000 の粒度）
- 代表色5色までと、その面積比
- 平均輝度・コントラスト、主方向、重心、余白率、8×8 の粗い濃度格子

次のものは含みません。原画および原画由来の画素、抽出時の設定値、内部識別子は含みません。
会話の記録（発話・時刻・件数・割合）は含みません。個人を特定する情報は含みません。

輪郭は抽出時から点数を 24,546 → 10,670（56.5%）に縮約しています。
元になった画像は `../visual-materials/` で既に公開されているため、このデータがそれ以上のものを開示することはありません。

## 表示上の配慮

- `prefers-reduced-motion: reduce` では、描き出しを完了させた静止状態で表示します
- キーボード操作とフォーカス表示を維持します
- G/B や選択状態を色だけで区別しません（記号・チェック状態・テキストを併用）
- `noindex,nofollow,noarchive` を指定しています。これは検索結果に出にくくする指定であり、
  アクセス制御ではありません。URL を知っていれば誰でも閲覧できます。

## 常設注意書き

> この作品は、公開済みの会話テーマと視覚資料の構成を、同じ場に置き、色・線・動きとして翻訳する試作です。
> 会話テーマは作品の変わり方を、視覚資料は描かれる輪郭・色・構図をそれぞれ決めます。
> 画面に現れる近接や変化は、個人どうしの関係、心理状態、因果関係、テーマと資料の対応を示すものではありません。
