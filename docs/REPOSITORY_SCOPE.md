# Repository Scope

## Git管理対象

Git管理の対象は、データに依存しない方法論文書、コードブック、再現用スクリプト、依存関係の固定ファイル、README、および安全な除外設定に限ります。

## 除外対象

`sources/`、`private/`、`derived/`、`models/`、音声、動画、文字起こし、CSV、ログ、環境変数はGit管理から除外します。

個人情報、要配慮情報、識別子、対応表、実データの内容は保存しません。

## コミット前の確認

コミット前に `git diff --cached` を確認し、発話本文、引用、要約、個人名、識別子、要配慮情報、実データへの参照、認証情報が含まれていないことを確認します。

## 将来のスクリプト

実データを使う処理スクリプトを将来追加する場合も、固定パス、実データ名、識別子をコードに書きません。必要な入力はコマンド引数またはローカル設定から受け取ります。

要配慮情報の具体例、検出語彙、件数、時刻、識別子は、リポジトリに記録しません。
