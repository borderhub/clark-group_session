表現形式・構成の件数

視覚資料

画像を選ぶと拡大表示します。作品ごとの作成者名・個別の解説・個別の解釈は表示していません。

うち1点は、紙面に書き込まれていた氏名の部分のみを不可視化しています。それ以外の加工は行っていません。

会話データとの接続範囲

視覚資料と会話データは、セッション単位でのみ照らし合わせています。個々の作品を特定の発言・発言者に結びつけることはしていません。

  • できること：同じセッションで、会話でも扱われた主題が視覚資料にも併存して観察された可能性を示すこと。
  • していないこと：作品と作成者の対応づけ、作品と特定の発言の対応づけ、因果関係の主張。
  • 扱わないこと：心理状態、性格、発達、能力の評価。性別による一般化。GとBの優劣比較。

G・Bは今回の2セッションを区別するための呼称であり、集団の属性を表すものではありません。参加者は各セッション7名の小さな標本で、結果を一般化することはできません。
