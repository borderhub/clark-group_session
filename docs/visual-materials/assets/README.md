# 公開用画像

グループディスカッション中に制作された視覚資料 8 点の公開用コピーです。

| ファイル | 区分 |
|---|---|
| `group-g-01.jpeg` 〜 `group-g-04.jpeg` | セッションG（4 点） |
| `group-b-01.jpeg` 〜 `group-b-04.jpeg` | セッションB（4 点） |

## 作成方法

1. 原資料から、メタデータを除去した処理済みコピーを可逆変換で作成。
2. そのコピーを公開用ファイル名にリネーム。
   ファイル名には元ファイル名・内部の資料ID・参加者IDを使用していません。
3. `group-g-01.jpeg` のみ、紙面に書き込まれていた氏名の部分を不可視化。
   それ以外の加工（トリミング、修正、色調整、生成加工）は行っていません。

## メタデータ

全 8 点とも EXIF・GPS・XMP・IPTC を含みません。残っているのは JPEG の符号化ヘッダのみです。

## 扱いについて

- 画像は、作成者を特定せずグループ単位で閲覧するために公開しています。
- 作品と個人の対応づけは行っていません。作成者の心理状態、性格、発達、能力を
  示すものとして扱わないでください。
- G・B は今回の 2 セッションを区別するための呼称です。
