# 視覚資料アーカイブ（チーム確認用・暫定公開）

グループディスカッション中に制作された視覚資料 8 点を、作成者を特定せずグループ単位で
記録・閲覧するためのページです。

公開URL: https://borderhub.github.io/clark-group_session/visual-materials/

## 重要：これはアクセス制限ではありません

`index.html` には `<meta name="robots" content="noindex,nofollow,noarchive">` を入れていますが、
**これは検索エンジン向けの補助的な指示であり、アクセス制限ではありません。**
URL を知っている人は誰でも閲覧できます。公開済みの内容は第三者のキャッシュやアーカイブに
残る場合があり、後から公開範囲を変更しても、それらは消えません。

## 公開しているファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面本体 |
| `visual.css` | スタイル |
| `visual.js` | ギャラリー・拡大表示・集計の描画 |
| `visual_data.js` | グループ単位の集計と、各資料の形式コード |
| `assets/*.jpeg` | 公開用画像 8 点 |

外部ライブラリ・外部フォント・CDN・外部通信は使用していません。

## 表示内容の性質

- 記録しているのは、**表現形式・構成・テキスト要素の有無・会話との関係**という
  造形上の特徴のみです。作品の内容の説明、画像内テキストの転記は行っていません。
- 作成者は特定しておらず、**作品と個人の対応づけは行っていません**。
  すべての資料を「グループ単位の補助資料」として扱っています。
- 表現を心理状態、性格、発達、能力の評価として扱いません。
- G・B は今回の 2 セッションを区別するための呼称であり、集団の属性を表すものではありません。
  セッション間の優劣比較、性別による一般化は行いません。
- 会話データとの関係は「同じセッションで併存して観察された可能性」にとどめ、
  因果関係としては解釈しません。個々の作品と特定の発言・発言者は結びつけていません。
- AI 補助による暫定的・記述的な整理であり、人間の確認を経ていない項目を含みます。

## 画像について

- 公開画像は、メタデータを除去した処理済みコピーから作成しています。
  EXIF・GPS・XMP・IPTC はいずれも含まれません。
- ファイル名には、元ファイル名・内部の資料ID・参加者IDを使用していません。
- **8 点のうち 1 点は、紙面に書き込まれていた氏名の部分のみを不可視化しています。**
  それ以外のトリミング・修正・加工は行っていません。

## 公開していないもの

- 原資料の画像、発話本文、直接引用、音声・映像
- 参加者ID、話者ID、氏名、時刻、音声・映像・クリップのパス
- 作成者と作品の対応表、同意記録、分析台帳、コーディング台帳、生成スクリプト

これらはリポジトリの `.gitignore` により、公開範囲に含まれません。
